# Rohrreinigung Falkenhagen, Vorschau zur Abstimmung

Statische Vorschau des neuen Frontends. Dient allein der Abstimmung und ist
nicht die Website des Betriebs.

**Vorschau:** https://edgarpauledge.github.io/falkenhagen-vorschau/

## Was diese Fassung nicht kann

Die ausgelieferte Website läuft auf einem Server mit PHP. Diese Vorschau
liegt auf einem Webspace ohne PHP und ist deshalb eingefroren:

- Das **Kontaktformular verschickt nichts.** Beim Absenden erscheint ein
  Hinweis. Auf dem Zielserver geht die Anfrage an die hinterlegte Adresse.
- Es gibt **keine Sitemap**, sie würde auf die Live-Adresse zeigen.
- Jede Seite trägt **noindex**, `robots.txt` sperrt alles. Diese Fassung
  soll nicht in Suchmaschinen erscheinen und der echten Seite nicht ins
  Gehege kommen.

Alles Übrige entspricht der Auslieferung: dieselben Texte, dasselbe Layout,
dieselbe Technik.
